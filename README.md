# About This Project: Gym Tracker

_Please note I am actively in development on this app, it is currently not published or available for preview. However, if you are interested in my progress on this app, please visit the repo to see the code I have completed so far_

My current in development project is a React Native app I am building to track my training sessions at the gym. Other apps I had tried always had something I would prefer to be designed differently, so I decided to build an app customised to my preferences for tracking my workouts.

The early version of the app is close to complete, which I will be using with the basic functionality of tracking each workout, creating & editing workout templates with preset exercises, and setting a training split. Users can substitute an exercise from a training template during an active workout, such as if equipment is broken.

In future I will be adding group features to use with friends, including shared training splits, the ability to add workout templates created by other users and view each other's active workout streak.

Future features for personal use I also intend to implement include milestone tracking, plus the ability to set and track progress towards custom training goals, and a feed of workouts completed by app friends.

_Tech Stack_

- React Native
- TypeScript
- HTML
- CSS Modules
- NextJS
- NodeJS
- PostgreSQL

_Development Challenges & Growth_

Having previously completed multiple browser based react projects, to continue expanding my skillset I decided to build this as a native app instead of website. This has meant continual learning about the differences in React Native development. 

I also began using TypeScript instead of JavaScript on this project. I have often faced and resolved errors related to enforcing types which I would have previously not have encountered. Rectifying these errors has helped me improve my component design and better guard against potential errors during app usage with branching based on data types and existence.

This project has further expanded in scope compared to previous completed sites, which taught me the importance of implementing features one at a time. This allows my app to continue functioning locally while expanding with new features progressively, as opposed to picturing the final envisioned product and attempting to complete all at once.
